# DataPortfolio

Portfolio repository for multi-domain analytics assets, sample datasets, and a lightweight static site.

## Repository Layout

Code and documentation live here, in git. **Data does not:** every dataset lives in OneDrive (see below).

- `index.html`, `sme.html`, `not-for-profit.html`, `work.html`, `how-we-work.html`, `about.html`, `styles.css`, `script.js`: the website (GitHub Pages).
- `dashboard-data.js`, `media/exports/`: the home-page sample dashboard and its Excel/PDF downloads (generated).
- `Assets/`, `media/`, `game/`, `versions/`: images, the game and the themed old versions.
- `tools/`: Python that generates the sample model, daily star schema, CSVs, exports, mock-ups and old versions.
- `datasets/<domain>/`: scripts and documentation for the Health, Legal and Purchasing datasets (the data itself is in OneDrive).
- `PLACEHOLDERS.md`: open decisions and the go-live checklist for the website.

## Where the data lives

All data files (CSV, Excel) are kept in OneDrive so they're backed up to cloud storage, and are excluded from git:

```
~/Library/CloudStorage/OneDrive-Personal/Projects/The 4th Sheet/
  Data/
    Health/  Legal/  Purchasing/  Retail/   datasets used by datasets/*/scripts
    Website sample data/                    generated by tools/sample_data.py (CSVs + schema.sql)
  Owner documents/  Other assets/  Plans/   business documents
```

Scripts find this folder automatically. To use another location, set `FOURTH_SHEET_DATA` (in `.env` or the shell) to the `Data` folder.
The only spreadsheets kept in git are the website's own downloads in `media/exports/`.

## Quick Start

Run from the repository root (`dataPortfolio`):

```
python3 -m http.server 8765        # then open http://127.0.0.1:8765
python3 tools/sample_data.py       # regenerate the sample model, downloads and CSVs
```

## Prerequisites

- Python 3 available in PATH (`python`, `py -3`, or `python3` depending on platform).

## Data and Reporting Notes

- Legal reporting models target PostgreSQL `portfolio_data` and schema `legal`.
- Purchasing (and, going forward, Health/Legal/Retail and the website sample data) targets Azure SQL database `3sheets.db.sql`
  on server `3sheets`, one schema per domain. **The database is currently deleted and needs recreating (to do).** See
  `datasets/Purchasing/Docs/Purchasing Azure SQL Upload Steps.md`.
- Keep table and view names stable when modifying loaders or model scripts.
- Health and legal datasets are synthetic and intended for portfolio analytics/reporting demos.
